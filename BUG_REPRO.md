# 缺陷复现说明

## 缺陷现象
月末批量过账时，操作员连点或两个任务同时提交同一张已审核凭证，账面余额偶尔会变成原金额的好几倍，审计里也会出现重复过账。帮我修好同一凭证只能被成功过账一次的问题。

## 触发方式
# 1. 进入测试项目根目录；预期：后续命令在目标项目内执行。
cd /workplace/accounting-system-headless
# 2. target-verify 以同步屏障同时触发同一凭证的过账；预期：未修复时存在重复成功或竞态。
go test -race -v ./internal/service -run '^TestConcurrentPostAppliesVoucherOnlyOnce$' -count=20
# 3. 修复后运行完整测试集；预期：常规业务回归通过。
go test ./...
